# Siete Días en Chicago

App del viaje del 13 al 19 de septiembre de 2026.

- `index.html` — la app completa (sin dependencias, se sirve como sitio estático)
- `data.json` — el estado compartido: la vaca, los pendientes, los checks y las decisiones

**Una sola escritora.** María Luisa entra en "Modo administradora" con un token de GitHub
(guardado sólo en su navegador) y sus cambios se escriben en `data.json`. Todas las demás
abren el mismo link y lo ven en modo lectura, refrescando cada minuto.
